ЗАЯВКИ НА ЗЕРКАЛА И СТЕКЛО — ВЕРСИЯ 1.0 (тестовая сборка)

Состав: app.py — приложение; Собрать_EXE.bat — сборка EXE; requirements.txt — зависимости.

СБОРКА: на Windows 10/11 установите Python 3.11+ и запустите Собрать_EXE.bat.
После сборки скопируйте dist\ЗаявкиЗеркала.exe в общую сетевую папку с правами чтения/записи.
Запускайте EXE из Проводника Windows. Данные будут храниться в Заявки.json рядом с EXE.

ПОЛЬЗОВАТЕЛИ: выбираются вверху. Это выбор роли, НЕ защищённая паролем авторизация.

БЛОКИРОВКА: первый запущенный экземпляр получает право редактирования. Второй — просмотр.
Чтобы получить право записи после завершения работы другого сотрудника, закройте и снова откройте программу.
Блокировка основана на Windows byte-range lock файла Заявки.lock. Перед внедрением проверьте её на вашей сетевой папке SMB.
Не удаляйте файл блокировки во время работы программы. После аварийного завершения ОС освобождает файловую блокировку.

PDF: выберите строку товара нужной заявки, затем «PDF заявки». PDF не содержит оформителя, итогов или подписей.

ОГРАНИЧЕНИЯ: приложение не проверено в среде Windows в этой сессии; сборку и испытания надо выполнить на месте.
Исторические данные ODS не импортированы. Резервные копии JSON сохраняются при каждом изменении (до 100 последних).
Перед началом эксплуатации протестируйте одновременный запуск, отключение сети, экспорт PDF и восстановление из копии.
