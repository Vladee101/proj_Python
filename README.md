# Заявки на зеркала и стекло

[![Build EXE](https://github.com/Vladee101/proj_Python/actions/workflows/build-exe.yml/badge.svg)](https://github.com/Vladee101/proj_Python/actions/workflows/build-exe.yml)

Desktop-приложение (PySide6) для учёта заявок на изготовление и поставку зеркал и стекла. Предназначено для работы из общей сетевой папки SMB: данные хранятся в одном JSON-файле, право редактирования получает первый запущенный экземпляр (Windows byte-range lock файла `Заявки.lock`), остальные работают в режиме просмотра.

## Возможности

- Заявки с товарами: артикул, наименование, характеристики, размеры, количество, ожидаемая дата, поставщик
- Роли: **Оформитель** (создание/редактирование заявок) и **Приёмщик** (принял/возврат) — выбор сотрудника без пароля
- Жизненный цикл товара: Ожидаем → Принято / Возврат → Снова ожидаем
- Журнал всех действий с деталями «до/после» при редактировании
- Экспорт заявки в PDF (reportlab)
- Индикатор состояния на главном экране: ✓ Сохранено / 🔒 Режим просмотра / ⚠ Ошибка сохранения
- Атомарная запись JSON (temp + `os.replace` + fsync) и до 100 резервных копий

## Запуск из исходников

```bash
py -m pip install -r ЗаявкиЗеркала_v1/requirements.txt
py ЗаявкиЗеркала_v1/app.py
```

Требуется Windows 10/11 и Python 3.11+ (используется `msvcrt` для сетевой блокировки).

## Сборка EXE

- **Локально**: запустить `ЗаявкиЗеркала_v1/Собрать_EXE.bat` → готовый файл `dist\ЗаявкиЗеркала.exe`
- **Автоматически**: GitHub Actions собирает EXE при каждом push в `main` (вкладка Actions → артефакт `ZayavkiZerkala-exe`), а при пуше тега `v*` создаёт GitHub Release с EXE

## Данные (рядом с EXE)

| Файл/папка | Назначение |
|---|---|
| `Заявки.json` | все заявки и журнал событий |
| `Заявки.lock` | блокировка права редактирования (не удалять во время работы) |
| `Резервные_копии/` | автоматические бэкапы при каждом изменении (до 100) |

Подробности эксплуатации — в [README.txt](ЗаявкиЗеркала_v1/README.txt).
